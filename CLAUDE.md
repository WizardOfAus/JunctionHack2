# Claude Code entry point

Read and follow [AGENTS.md](AGENTS.md), then [CONTRIBUTING.md](CONTRIBUTING.md) and your assigned package in [docs/workstreams.md](docs/workstreams.md).

The app is in `app/`. Start from current `main` in your own branch/worktree. The current implementation is a working single-persona demo; [onboarding](docs/onboarding.md) describes the proposed next behavior. Do not independently edit the shared app shell or global styles while another contributor owns integration.
