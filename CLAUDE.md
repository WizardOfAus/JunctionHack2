# Claude Code entry point

Read and follow [AGENTS.md](AGENTS.md), then [CONTRIBUTING.md](CONTRIBUTING.md) and your assigned package in [docs/workstreams.md](docs/workstreams.md).

The app is in `app/`. Start from current `main` in your own branch/worktree. It has eight synthetic personas, goal-led onboarding and a shared Money/Learn/Coach/Plan journey. Read the [UI/UX handoff](docs/claude-ui-handoff.md) before continuing design work: it records shipped behavior, reference principles, verification and ownership. Coordinate shared-shell or global-style changes with any active integration owner.
